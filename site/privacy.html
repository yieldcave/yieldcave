Privacy Policy

Version 0.1, effective 10 October 2026. Draft for review; may change before launch.

What we collect

  • Email address, when you create an API key. Used to identify the key, contact you about it, and prefill Stripe checkout.
  • API keys, stored only as SHA-256 hashes. We cannot recover a lost key.
  • Usage counts: the number of tool calls per day per key, or per hashed IP address for anonymous callers. Anonymous IP addresses are hashed with a project-specific value before storage; raw addresses are not stored by us.
  • Alert rules you create, including the webhook URL you register.
  • Billing references: a Stripe customer ID and subscription ID. Stripe collects and holds your payment details under its own privacy policy; we never see card numbers.

The yieldcave.com website sets no cookies and runs no analytics. The live table on the home page fetches public data directly from DefiLlama in your browser, so DefiLlama sees that request. Our hosting providers (Cloudflare, Supabase) keep standard server logs, which may include IP addresses and request URLs; if you put an API key in a connector URL, that URL may appear in those logs.

Why we use it

To run the Service, enforce plan limits, deliver alerts, bill paid plans, prevent abuse, and respond to you. We do not sell personal information or use it for advertising.

Who else sees it

  • Supabase (database and functions, hosted in Sydney, Australia).
  • Cloudflare (website hosting and network).
  • Stripe (payments, billing portal, invoices).
  • Your own webhook endpoint, for alerts you create.

We disclose information if the law requires it.

How long we keep it

Key and billing records for as long as the key exists, plus any period required for tax and accounting. Daily usage counts for 13 months. You can ask us to delete your key and associated records at any time.

Your rights

You can ask what we hold about you, ask for corrections, or ask for deletion. If you are in the EU or UK, you also have the rights set out in the GDPR, including to object and to complain to a supervisory authority. We handle personal information in line with the Australian Privacy Principles. To make a request, open an issue at github.com/yieldcave/yieldcave/issues (do not include your key) or use the contact address on yieldcave.com when published.

Changes

We will post changes here with a new version number and date.
