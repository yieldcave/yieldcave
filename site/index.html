Why a read-only layer

Agents will soon shop for yield the way they already shop for flights. Something has to be the index they consult.

No custody, no execution

YieldCave never holds funds or routes orders. It returns data and arithmetic. That keeps it simple to run and simple to trust.

Built for models, not dashboards

Every field is named for a language model to read. Every response carries its fetch time, source and a disclaimer.

Open source, free to run

MIT licensed. Hosted for free with history and alerts, or run it on your machine with one command.

Install

Hosted. Nothing to run, no account needed to start.

Claude Code

claude mcp add --transport http yieldcave https://ccvhvxbqtvqbhexhrjnj.supabase.co/functions/v1/mcp

claude.ai: Customize → Connectors → Add custom connector → paste the URL above and choose "No sign-in". With a key (Free or Pro allowances), put the key in the URL, since claude.ai cannot send headers:

https://ccvhvxbqtvqbhexhrjnj.supabase.co/functions/v1/mcp?key=yc_your_key

Any MCP client that speaks Streamable HTTP works. Then ask your agent: "Summarize the tokenized treasury market."

Self-host (optional, MIT licensed, Node 20+):

git clone https://github.com/yieldcave/yieldcave.git && cd yieldcave && npm install
npm run demo        # see the data in your terminal
npm start           # local stdio MCP server for Claude Desktop or Cursor

Sixteen tools

  • list_rwa_yields, get_rwa_asset, rwa_market_summary — tokenized treasuries and other RWAs, by chain, token or in total
  • list_stablecoin_yields, stablecoin_yield_summary — where USDC, USDT, DAI and friends earn yield, with lending, vault, credit and basis venues labelled
  • compare_yield_to_tokenized_treasuries — simple-interest arithmetic against the best liquid tokenized treasury
  • rwa_issuer_terms — who may invest, minimums, redemption, fees, legal structure, with sources and a verified date
  • rwa_history, rwa_changes — daily snapshots and what moved since N days ago, for either universe
  • create_alert, list_alerts, delete_alert — hourly checks that POST to your webhook when a treasury or stablecoin threshold is crossed
  • create_api_key, my_usage, upgrade, manage_subscription — keys, allowances and billing
